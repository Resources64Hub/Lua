--- AN_X Remake Version 0.5 Commands:

!playanimationid Arg[1] Arg[2] Arg[3] -- Plays an animation based on his ID from roblox (Please make sure that the animation you want to play is public!) Arg[1] - Animation ID (Number) Arg[2] - Looped (true/false) Arg[3] - Speed (Number) ... Example of a Command: !playanimationid 10214406616 true 15

!fuck Arg[1] Arg[2] -- Everything is clear from the name. (Attention The animation only works with the R6 rig) Arg[1] - Traget USERNAME! (String) Arg[2] - Speed (Number) ... Command Example: !fuck Tajikiar 200

!follow Arg[1] -- Chasing the designated player Arg[1] - Target USERNAME! ... Command Example: !follow Tajikiar
